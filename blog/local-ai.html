Why I Started Running AI Models Locally

Cloud AI is convenient. But running a model on my own computer changed how I think about AI development.

Curiosity came first

I had used AI through online tools, but that hides most of the machinery. I wanted to know what it feels like to actually run an inference model on a personal computer.

That led me to Ollama. Instead of building a complicated inference stack from scratch, Ollama gives me a practical way to download and run compatible language models locally.

My first useful experiment

My laptop has an Intel Core i5-13420H, RTX 2050, and 16 GB of RAM. That is not workstation hardware, so model size matters. I started with Qwen 2.5 3B because a smaller model makes local experimentation realistic.

The interesting part was not simply getting a response from the model. It was connecting that model to an application. In MovieGPT, Qwen sits inside a larger pipeline and works alongside traditional Python code.

Why local inference is useful

Local models can offer privacy advantages because prompts do not have to leave the machine. They are also useful for learning: I can experiment with prompts, model settings, application logic, and failures without designing a production cloud architecture first.

There are trade-offs. Smaller local models can be less capable than larger hosted models, hardware limits inference speed, and a local setup requires managing storage, memory, and model resources.

The bigger lesson

For me, local AI is less about replacing cloud services and more about understanding the technology. When the model runs on my machine, the boundary between AI and software engineering becomes much clearer.

My current rule: use the smallest model that is good enough for the job, then let deterministic software handle the parts that should be deterministic.

Where I want to go next

I want to explore larger local models, structured outputs, tool calling, FastAPI backends, and AI agents. The goal is not just to run models — it is to build useful systems around them.
